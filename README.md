# SearchDemonSlayerAPI

Aplicação web desenvolvida como atividade acadêmica da disciplina **Desenvolvimento Web: Usabilidade, Desenvolvimento Web, Mobile e Jogos**

O projeto consome a API de Demon Slayer e permite selecionar personagens para consultar suas informações, incluindo nome, idade, raça, citação e imagem.

## Tecnologias

- .NET 10
- Blazor WebAssembly
- API de Demon Slayer: https://www.demonslayer-api.com/api/v1/characters?page=1

## Como executar

Pré-requisito: SDK do .NET 10 instalado.

Na pasta do projeto, execute:

```bash
dotnet run
```

Abra no navegador o endereço local exibido no terminal.
